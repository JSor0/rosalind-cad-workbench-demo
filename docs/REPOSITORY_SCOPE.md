# Curated repository scope

Included: four final requested PNGs, final GIF, exact query coordinates and all 22 family inputs, complete native forward/reverse tables and alignments, saved settings/logs, current sequence-search FASTAs/output, six small deposited processed-expression matrices, genomic source records and saved checks, used analysis/composition code and concise current provenance.

Excluded: draft and superseded figures, revision history, cache/binary/runtime files, raw sequencing reads, unrelated thesis/lab documents, source PDFs, Martin teaching material, failed agent payloads, full archived viewer and unrelated dimer–DNA predictions. The broader illustrated work and specialist phylogenies are preserved in the existing project; this selected repository does not delete or replace them.

Sanitization removes local filesystem/account namespaces only. Original source hashes are retained for traceability. No placeholder bytes are substituted for an unavailable artifact. The archival viewer and native FoldMason report application remain external rather than fake local targets.
